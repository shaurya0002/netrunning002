# Certification Path

| Order | Cert | When | Notes |
|---|---|---|---|
| 1 | CompTIA Security+ | After Phase 2 | Good foundation, HR-recognized, optional if budget tight |
| 2 | eJPT (INE) | After Phase 3 | Cheap, practical, great first offensive cert |
| 3 | PNPT (TCM Security) | After Phase 4 | Realistic pentest exam incl. AD + reporting, well-regarded, affordable |
| 4 | OSCP (OffSec) | After Phase 5/6 | Industry gold standard, expensive — do once portfolio + boxes are strong |
| Optional | CEH | Anytime | Widely known name but less hands-on respected than eJPT/PNPT/OSCP; only if a job listing specifically asks for it |

Don't over-invest in certs before you have boxes/CTFs/writeups — practical proof matters more for entry-level roles.

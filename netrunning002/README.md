# NetRunning 002 — Cybersecurity Roadmap (CS Student → Job-Ready Ethical Hacker)

Goal: become a job-ready **ethical hacker / penetration tester** (with solid blue-team fundamentals) by graduation, using free/cheap resources and lots of hands-on labs.

> Ethical hacking = hacking **only with written permission** or on **legal practice targets** (your own lab, CTF platforms, bug bounty scope). Read `00-start-here/legal-ethics.md` first.

## How this repo works
| Folder | What's inside |
|---|---|
| `00-start-here/` | Legal/ethics, lab setup, how to study |
| `01-foundations/` | Networking, Linux, Windows, Python/Bash |
| `02-security-core/` | Crypto, web basics, OWASP, threat modeling |
| `03-offensive/` | Recon → exploitation → privesc → AD → reporting |
| `04-defensive/` | Logs, SIEM, detection, incident response |
| `05-specializations/` | Web/API, cloud, mobile, malware analysis, red team |
| `labs/` | Lab roadmap + tracker (TryHackMe, HTB, PortSwigger, etc.) |
| `tools/` | Small Python scripts for **your own lab** |
| `cheatsheets/` | Quick reference (nmap, Linux, web, privesc) |
| `certs/` | Cert path + exam prep |
| `career/` | Portfolio, resume, interviews, bug bounty |
| `progress/` | Weekly log template |

## The plan at a glance
| Phase | Months | Focus | Milestone |
|---|---|---|---|
| 0 | Week 1 | Ethics + lab setup | Kali + vulnerable VMs running |
| 1 | 1–3 | Networking, Linux, Python, Windows basics | Comfortable in terminal, read packets in Wireshark |
| 2 | 3–5 | Security core + web basics | Finish PortSwigger fundamentals, TryHackMe Pre-Security → Jr Pentester |
| 3 | 5–8 | Offensive: recon, exploitation, privesc | 30+ easy/medium rooms/boxes, eJPT |
| 4 | 8–10 | Active Directory + reporting | Own AD lab, PNPT-level skills |
| 5 | 10–12 | Specialize + portfolio + bug bounty | 5 public writeups, first bug bounty attempts |
| 6 | 12+ | OSCP-level prep, internships, jobs | Cert + portfolio + applications |

Study time: ~10–15 hrs/week alongside college. Adjust the pace, keep the order.

## Rules
1. Hands-on > watching. Every topic = notes + a lab.
2. Write notes in your own words (this repo is your second brain).
3. Every box/room you finish → a short writeup in `labs/writeups/`.
4. Commit weekly. A green GitHub graph is part of your portfolio.

# Linux (Phase 1, ~3 weeks)

## Must know
- Filesystem layout (`/etc`, `/var/log`, `/home`, `/tmp`, `/proc`)
- Users, groups, permissions (`chmod`, `chown`, SUID/SGID, sticky bit)
- Processes, services (`systemctl`), cron jobs
- Text tools: `grep`, `sed`, `awk`, `cut`, `sort`, `uniq`, `find`, `xargs`, `tar`
- Networking: `ip a`, `ss -tulpn`, `curl`, `wget`, `nc`, `ssh`, `scp`
- Package managers, environment variables, PATH, bash scripting

## Practice
- OverTheWire **Bandit** (levels 0–34) — do all of them
- TryHackMe: Linux Fundamentals 1–3, Linux PrivEsc (later)
- Write 5 bash scripts (backup, log parse, ping sweep of your lab, etc.)

## Resources
- "The Linux Command Line" (William Shotts, free)
- Linux Journey (linuxjourney.com)

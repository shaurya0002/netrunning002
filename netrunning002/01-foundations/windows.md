# Windows Basics (Phase 1–2)

## Must know
- File system, registry, services, scheduled tasks
- Users/groups, UAC, local admin vs domain admin
- PowerShell basics (`Get-Process`, `Get-Service`, `Get-ChildItem`, pipelines)
- CMD essentials (`whoami /all`, `net user`, `ipconfig`, `netstat`)
- Event Viewer logs (4624 logon, 4625 failed logon, 4688 process creation)
- SMB, RDP, WinRM, NTLM basics, Kerberos overview

## Practice
- TryHackMe: Windows Fundamentals 1–3, Windows PrivEsc (later)
- Setup a Windows VM, poke around Event Viewer and Task Scheduler

# Networking (Phase 1, ~4 weeks)

## Must know
- OSI vs TCP/IP model; encapsulation
- IP addressing, subnetting (CIDR), NAT, private ranges
- TCP 3-way handshake, flags (SYN/ACK/FIN/RST), UDP
- DNS (A, AAAA, MX, TXT, NS, CNAME), DHCP, ARP, ICMP
- HTTP/HTTPS, TLS handshake, cookies, headers, status codes
- Common ports: 21 FTP, 22 SSH, 23 Telnet, 25 SMTP, 53 DNS, 80/443 HTTP(S), 110/143 mail, 139/445 SMB, 389/636 LDAP, 3306 MySQL, 3389 RDP
- Routers, switches, VLANs, firewalls, IDS/IPS, proxies, VPNs

## Practice
- Wireshark: capture a login over HTTP vs HTTPS, follow TCP stream
- Subnetting drills (subnetting.net), 20 problems until fast
- `nslookup`, `dig`, `traceroute`, `netstat/ss`, `curl`
- TryHackMe: Pre-Security path, Network Fundamentals

## Resources
- Professor Messer Network+ (free videos)
- Cisco Networking Academy (free intro courses)
- "Computer Networking: A Top-Down Approach" (Kurose) for depth
- Practical Networking (YouTube) for subnetting

## Checkpoint
Can you explain what happens when you type a URL and press Enter, end to end? If yes → move on.

# Cryptography (practical level)

## Must know
- Symmetric (AES) vs asymmetric (RSA, ECC); modes (CBC, GCM, ECB weakness)
- Hashing (SHA-2/3, MD5/SHA-1 broken), salting, bcrypt/scrypt/argon2
- HMAC, digital signatures, certificates, PKI, TLS 1.2/1.3
- Key exchange (Diffie-Hellman); common mistakes (hardcoded keys, weak RNG, reused IVs)
- Encoding vs encryption vs hashing (Base64 is NOT encryption)

## Practice
- CryptoHack (free challenges), PicoCTF crypto, TryHackMe Crypto rooms
- Use `openssl` to generate keys, certificates, hashes
- Inspect a real TLS certificate chain in a browser

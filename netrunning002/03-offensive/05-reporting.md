# Reporting (the skill most students skip — recruiters care a lot)

## Every lab/box writeup should include
1. Target & scope (or "personal lab")
2. Recon summary (ports/services found)
3. Vulnerability found + how you found it
4. Exploitation steps (commands, screenshots)
5. Impact (what could an attacker do)
6. Remediation/fix
7. Lessons learned

## Practice
- Write a full professional pentest report for one HTB/THM box using a public report template (search "pentest report template" — many free ones)
- Publish sanitized writeups on GitHub/blog (this becomes your portfolio)

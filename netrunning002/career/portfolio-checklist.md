# Portfolio & Career Checklist

## Portfolio pieces
- [ ] GitHub with this repo + your `tools/` scripts, clean commit history
- [ ] 5–10 published lab writeups (sanitized, no confidential data)
- [ ] Personal blog or GitHub Pages site summarizing projects
- [ ] LinkedIn updated with projects, certs, TryHackMe/HTB profile links
- [ ] Resume: 1 page, projects + labs + certs + any CTF placements

## Resume bullets (fill in as you progress)
- "Rooted X HTB machines across Linux/Windows/AD, documented in public writeups"
- "Built [tool] in Python to automate [task] for personal security lab"
- "Completed TryHackMe Jr Penetration Tester path (X rooms) and PortSwigger Academy (all web vuln categories)"

## Where to apply (India-relevant + global)
- SOC Analyst / Security Analyst (entry point, good for freshers)
- Junior Penetration Tester
- Bug bounty (HackerOne, Bugcrowd) — supplemental income + portfolio, not a first job replacement
- Internships: look for cybersecurity internships via LinkedIn, Internshala, company career pages

## Interview prep
- Be ready to walk through 2–3 boxes/writeups in depth
- Know OWASP Top 10 cold
- Practice explaining a vuln to a non-technical person (client communication matters)
- Mock interviews with study group/college cyber club

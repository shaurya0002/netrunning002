# Legal & Ethics (read before touching any tool)

## The one rule
**Only test systems you own or have explicit written permission to test.**
Unauthorized scanning/access can be a crime (India: IT Act 2000, Sec. 43 & 66; most countries have similar laws).

## Safe places to practice
- Your own VMs / home lab (isolated network)
- Legal platforms: TryHackMe, Hack The Box, PortSwigger Academy, PicoCTF, OverTheWire, VulnHub, DVWA/Juice Shop (local)
- Bug bounty programs — **only in-scope assets**, follow the program rules

## Never
- Scan/attack college, friends' or random websites "just to test"
- Access data you aren't supposed to see, even if it's exposed
- Run malware samples outside an isolated VM
- Use stolen credentials or leaked databases

## Professional habits
- Get **scope + rules of engagement** in writing before any test
- Log what you do (timestamps, commands)
- Report vulnerabilities responsibly (responsible disclosure; India: CERT-In can be contacted for incidents)
- Protect any data you touch; delete it after the engagement

## Bug bounty basics
Read the program policy: in-scope domains, banned techniques (DoS, social engineering, spam), safe harbor language. No scope = no testing.

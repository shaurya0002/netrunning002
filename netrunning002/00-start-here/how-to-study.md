# How to Study (Notes-Ready System)

## Weekly rhythm (10–15 hrs)
- Mon/Wed: theory (videos/reading) + notes in this repo
- Tue/Thu: labs (TryHackMe / PortSwigger)
- Sat: one bigger challenge (HTB box or CTF)
- Sun: writeup + commit + plan next week (`progress/weekly-log-template.md`)

## Note template for every topic
```
# Topic
## What it is (2 lines)
## How it works
## How attackers abuse it
## How defenders detect/prevent it
## Commands / payloads
## Lab done: (link)
```

## Rules
- Try for 30–45 min before looking at hints; then use hints, not full solutions
- After every solved box: what did I miss? what tool/technique is new?
- Build a personal cheat sheet as you go
- Join a community: local CTF team, college cyber club, Discord servers, OWASP chapters

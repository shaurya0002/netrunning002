# Lab Platform Roadmap

## Order of platforms
1. **TryHackMe** — Pre-Security → Complete Beginner → Jr Penetration Tester path (best structured start)
2. **PortSwigger Web Security Academy** — do alongside web fundamentals, it's free and excellent, aim to finish all Apprentice + Practitioner labs
3. **OverTheWire: Bandit** — Linux comfort, do early
4. **PicoCTF** — beginner CTF, great for scripting + crypto + web
5. **Hack The Box** — Starting Point (free) → Easy boxes → Medium boxes
6. **VulnHub** — free downloadable vulnerable VMs, unlimited practice
7. **CTFtime** — join live CTFs with a team once comfortable
